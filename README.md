# Dakka

A Star Empire mod. Purely cosmetic and client-only: while you are trained in
Way of the Hullbreaker, your shots (turrets included) are drawn as big,
staggered volleys. Nothing about gameplay changes.

![A Hullbreaker firing at a boss, each shot drawn as a long staggered volley](docs/dakka.png)

See [`source/README.md`](source/README.md) for details.

## Install

Grab the latest `.semod` from [Releases](../../releases/latest) and drop
it into the Star Empire Mod Manager.
